GhostWave Studio - Changelog & Release Notes

Version: 1.5.0
Release Date: 2026-10-10

What is new:
New on 10/10/2026:
	Fixed an issue where the selected interface language would revert back to default after closing and reopening the application. The configuration resolution logic had a path discrepancy during write operations, and the main window now triggers an immediate localization refresh on startup so your chosen language is active right away.
	The support ticket details viewer now shows complete ticket metadata at the top of the conversation view, including the ticket ID, subject title, category, status, submission date, and your original problem description instead of only showing replies.
	If a support ticket has been closed by the developer, the reply text box and send button are now disabled so you cannot accidentally submit replies to a ticket that is already resolved.
	Updated attribution and statements throughout the application, installer, and documentation to reflect that GhostWave Studio is developed by a single independent developer rather than an organization.
	Fixed several untranslated labels and tooltips in both the audio processing panel and lyrics cloaking view when running in Indonesian mode.
	Added an explicit application close handler to guarantee that user preferences, active language, and export settings are flushed to the encrypted profile container upon quitting.
	Added zero-length buffer and non-positive threshold checks to the soft limiting DSP module to guard against unexpected mathematical domain errors on silent passages.
	Guarded the Suno audio slicing algorithm against potential infinite division loops when handling very short chunk durations.
	Safeguarded clipboard write operations with reliable cleanup blocks so the operating system clipboard is never left locked if an unexpected error occurs during copy operations.
	Improved error parsing in the support ticket client to gracefully handle network timeouts and server responses.

	Added title bar updates reflecting the currently loaded audio file name.
	Added safety confirmation dialog before clearing populated lyrics.
	Added Select All (Ctrl+A) keyboard accelerators across multiline text controls.
	Added early exit guards for zero jitter intensity and zero-stage phase dispersion filters.
	Added silent execution flag (--no-banner) for automated scripting in the command-line interface.

Version: 1.2.0
Release Date: 2026-10-09

What is new:
New on 10/09/2026:
	Vectorized adversarial pseudo-peak injection using 2D NumPy array operations, eliminating python frame loops and reducing STFT processing latency.
	Added fast Fourier transform length padding with next_fast_len in both single and multi-band Bode frequency shifters to avoid prime length FFT slowdowns.
	Added second-order section filter coefficient caching for Butterworth and Schroeder all-pass biquads, avoiding repetitive trigonometric calculations.
	Vectorized Schroeder phase dispersion processing to run across all audio channels in contiguous float32 buffers.
	Replaced per-name iteration in celebrity and profanity blacklist filters with single-pass compiled regular expressions.
	Added LRU caching to syllable counting and phonotactic segmentation helpers to speed up lyrics cloaking on repeated verses.
	Added cooperative thread cancellation across the DSP pipeline with a dedicated Cancel button in the desktop interface.
	Throttled progress callback frequency to prevent wxPython event queue flooding on systems with constrained CPU resources.
	Added collapsible Show Advanced Settings toggle to clean up the primary audio interface.
	Disabled the short clip trimmer by default across all presets, configuration files, and command line options.
	Added hyperbolic tangent soft limiting before integer PCM export to prevent clipping on aggressive phase shifts.
	Added stereo cross-correlation safeguards in center vocal suppression to protect against mono phase cancellation.
	Added multi-threaded encoding parameters for FFmpeg conversions.
	Added zero-byte and non-finite sample checks to protect audio loading against corrupted files.
	Updated application version tracking across all dialog titles and CLI parameters to version 1.2.0.
